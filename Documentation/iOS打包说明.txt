当前交接的是团结源工程，不是 IPA，也不是已导出的 Xcode 工程。
源工程交接包：Build/iOS/Bufu-iOS-Source.zip。解压到Mac的本地目录后打开；不包含Library缓存或Windows运行包。
本机 Windows 编辑器只安装了 Windows/WebGL/微信模块，没有 iOS Build Support，无法在此完成 iOS 导出或签名。

在 Mac 上：
1. 安装与工程匹配的团结 2022.3.62t16（1.10.4）及 iOS Build Support，并安装 Xcode。
2. 打开源工程，等待资源导入。打开 Assets/Scenes/Main.unity。
3. 菜单「不服开一局/iOS/导出 Xcode 工程」，输出在 Build/iOS/Xcode。
4. 用 Xcode 打开输出工程，选择自己的 Team、唯一 Bundle Identifier 和签名配置，连接设备运行；需要 IPA 时执行 Archive 后按证书类型导出。

命令行可使用 Tools/export-ios.command。先将 UNITY_EDITOR 设置为本机编辑器可执行文件的绝对路径，再执行 bash Tools/export-ios.command。
可选环境变量 BUFU_IOS_BUNDLE_ID、BUFU_APPLE_TEAM_ID；默认 Bundle Identifier 为 com.rea.bufu，请改为签名账户下可用的值。
脚本配置 IL2CPP、ARM64、最低 iOS 13、竖屏，不内置证书或描述文件。构建成功后写入 Documentation/ios-build-result.json。
目前只验证 Windows 运行；iOS 导出、签名、触控和真机性能尚未验证。
