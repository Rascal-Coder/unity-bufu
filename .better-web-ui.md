## Design Context

### Users
Players of the original portrait idle game, using touch or mouse to flip coins, upgrade helpers, claim rewards and explore worlds.

### Brand Personality
Playful, lively and clear. Keep the original Chinese game's comic illustrations, warm parchment panels and celebratory effects, as requested throughout this reconstruction.

### Aesthetic Direction
The original game is the reference. Preserve existing layouts and art. The user explicitly requests text-only localization: list image lettering for the user to remake, without changing sprites or particle word textures.

### Implementation Defaults
Unity/Tuanjie 2022.3, original uGUI prefab JSON, TextMeshPro, original static CJK/Latin font atlas and Resources assets. Keep gameplay configuration and save identifiers independent of language.

### Design Principles
- Keep the original Chinese presentation as the default.
- Translate complete messages and keep numbers and rich-text values intact.
- Provide an explicit, persistent language choice in Settings.
- Make open panels update immediately without resetting progress.
- Fit longer English labels within their controls and preserve touch targets.
